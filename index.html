NOSSA MISSÃO

Mais autonomia.
Novas possibilidades.

O VERTEX é um projeto acadêmico que investiga uma cadeira de rodas controlada por ondas cerebrais através de uma interface cérebro-máquina. A plataforma web foi concebida para reunir informações de mobilidade, visualização de trajetos e indicadores de energia em uma experiência integrada.

✦Tecnologia desenvolvida com foco nas pessoas.
